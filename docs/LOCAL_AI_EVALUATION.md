# 로컬 AI 대체 실험 계획

상태: `experiment/local-ai` 브랜치에서 1차 구현·측정 중. 기본 사이트에는 적용하지 않는다.

## 2026-10-19 1차 실험 결과

- 현재 PC: Ollama 0.40.6, 설치 모델 `Gemma:latest` 약 5.0GB
- 공통 어댑터 `lib/ai-runtime.ts`를 추가해 답변 생성, 안내서 Q&A 추출, 업로드·감사 임베딩이 `AI_PROVIDER=openai|ollama` 설정을 사용하도록 연결했다.
- 비식별 민원 요약과 개인정보 보호법 제21조 근거를 구조화 JSON으로 생성하는 데 33.9초가 걸렸다.
- 요약과 법적 결론은 근거 범위 안에서 생성했지만 요구한 `[E1]` 표시는 누락했다. 기존 후처리가 근거 표시는 복구하지만, 소형 모델의 지시 준수는 별도 감점 대상이다.
- 로컬 임베딩은 DB의 `vector(1536)`과 같은 차원일 때만 저장한다. 후보 BGE-M3는 1024차원이므로 승인 없는 운영 DB 변경 대신 별도 실험 테이블 또는 마이그레이션이 필요하다.

## 2026-10-19 고정 평가셋 비교

평가 PC는 AMD Ryzen 5 7500F, RAM 15.6GB, NVIDIA GeForce RTX 5060이다. 실제 개인정보가 없는 합성 민원 3건과 고정 근거만 사용했다.

| 모델 | 용량 | JSON 형식 | 근거 누락 없음 | 미제공 조문 생성 없음 | 평균 | P95 |
|---|---:|---:|---:|---:|---:|---:|
| `Gemma:latest` | 5.0GB | 3/3 | 3/3 | 3/3 | 11.7초 | 13.8초 |
| `qwen3:8b` | 5.2GB | 3/3 | 3/3 | 3/3 | 18.0초 | 44.3초 |

- Qwen3의 44.3초는 최초 모델 적재를 포함한다. 적재 후 두 건은 각각 5.1초, 4.7초였다.
- Qwen3는 문장 구성과 쟁점 정리는 더 자연스러웠지만, 회원 탈퇴 후 두 달이 지났다는 사실만으로 보존 의무의 존재 여부를 확인하지 않고 즉시 파기 대상으로 단정했다. 운영 후보가 되려면 불확실성 표현과 근거 외 추론 차단 검증을 강화해야 한다.
- Gemma는 답변이 짧고 제공된 문구에 가깝게 작성되어 상대적으로 보수적이지만, 실무 답변의 논증과 안내 깊이는 부족했다.
- 두 모델 모두 이번 소규모 테스트에서는 형식, 근거 ID, 조문 환각 검사를 통과했다. 3건 결과만으로 정확성을 일반화할 수 없으며 실제 평가사례 20~30건의 담당자 검증이 필요하다.

### BGE-M3 검색 확인

- 모델 용량: 1.2GB
- 출력 차원: 1024
- 최초 3문장 임베딩: 8.3초
- 탈퇴 후 개인정보 파기 질의와 관련 문장 유사도: 0.6382
- 무관한 정보공개 절차 문장 유사도: 0.4272
- 소규모 순위 검사는 통과했지만 현재 운영 `vector(1536)`과 차원이 달라 운영 데이터와 혼합 저장할 수 없다.

재현 명령은 `pnpm test:local-ai-eval`이다. Ollama에 `Gemma:latest`, `qwen3:8b`, `bge-m3`가 설치되어 있어야 한다.

## 2026-10-20 단정적 추론 방지 보강

- 근거가 조건·예외를 포함하는데 답변이 이를 생략하고 즉시 파기·위법 여부 등을 단정하는지 규칙 기반으로 재검사한다.
- 위험 표현이 발견되면 `grounding_caution_valid=false`와 구체적인 경고를 반환하고, 완성된 초안에도 담당자 확인 문구를 붙인다.
- 생성 지시에도 조건 충족을 추정하지 말고 확인사항과 조건별 결론을 명시하도록 추가했다.
- 이 검사는 모델 출력의 정확성을 보증하는 장치가 아니라, 담당자가 놓치기 쉬운 고위험 표현을 표시하는 보조 장치다.
- 고정 평가 스크립트에 동일 검사를 추가해 모델별 `groundingPasses`를 비교한다.
- 강화 프롬프트로 Qwen3를 재평가한 결과 기존 즉시 파기 단정은 사라졌고, 다른 법령상 보존 의무와 처리 목적을 확인해야 한다는 조건부 답변으로 바뀌었다.
- 재평가 응답시간은 평균 7.0초, P95 11.3초였다. 초기 검증에서 안전한 “확인해야 합니다” 표현을 위험으로 본 오탐 1건은 회귀 사례를 추가해 수정했다.

## 2026-10-20 합성 민원 20건 확대 평가

- 파기, 전송요구권, 신용정보 제공, 위탁, 유출, CCTV, 국외 이전, 열람, 동의 철회, 목적 외 이용, 최소 수집, 민감정보, 고유식별정보, 자동화된 결정, 처리방침, 안전조치, 정정, 처리정지, 민원 처리기간을 포함했다.
- 최초 실행에서는 20건 중 2건이 반복 출력으로 JSON 끝이 잘렸다. Ollama에 반복 억제 옵션을 추가하고 로컬 출력 상한을 1,800토큰으로 제한한 뒤 20/20 JSON 형식 통과로 개선됐다.
- 보강 후 평균 응답시간 5.0초, P95 7.6초, 근거 인용 20/20, 미제공 조문 없음 20/20, 금지 단정 표현 없음 20/20이었다.
- 핵심 확인사항은 17/20으로 처음 집계됐으나 `보유 기간`/`보유기간`, `거절 사유`/`거절사유` 같은 띄어쓰기 차이 때문이었다. 공백 정규화 후 재검증 대상 4건은 4/4 통과했다.
- 처리정지 사례에서 “모든 시스템 처리를 즉시 중단하는 것은 의무가 아니다”라는 안전한 부정문을 금지 문구로 오인한 문제는 금지 표현 뒤의 부정어를 함께 판정하도록 수정했다.
- 이 평가는 합성 사례의 자동 검사이며, 실제 민원에 대한 법률적 정확성을 확정하지 않는다. 운영 판단에는 담당자가 검증한 비식별 실제 사례가 추가로 필요하다.

## 구현 환경변수

- `AI_PROVIDER=ollama`
- `OLLAMA_BASE_URL=http://127.0.0.1:11434`
- `OLLAMA_CHAT_MODEL=Gemma:latest`
- `OLLAMA_EMBEDDING_MODEL=bge-m3`
- `LOCAL_AI_TIMEOUT_MS=180000`
- `RAG_EMBEDDING_DIMENSIONS=1536` (현재 운영 스키마 보호용)

## 1차 판단

- 로컬 생성 경로는 기술적으로 동작한다.
- 현재 Gemma 모델은 한 건 생성에 약 34초로, 운영 응답시간과 복잡한 법률 지시 준수 측면에서 곧바로 대체하기 어렵다.
- 생성 1순위 후보는 Qwen3 8B이지만 단정적 추론을 막는 검증 계층을 추가한 뒤 확대 평가해야 한다.
- BGE-M3는 검색 후보로 유효하나 별도 1024차원 컬럼과 재임베딩·롤백 마이그레이션이 필요하다.
- 이 PC에서는 두 모델을 함께 운영할 수 있지만 모델 최초 적재 지연이 크므로 상시 로드 또는 워밍업, 요청 큐와 타임아웃이 필요하다.
- OpenAI 비교 평가는 로컬 셸에 `OPENAI_API_KEY`가 없어 이번 실행에서는 수행하지 않았다. 운영 비밀키를 실험 스크립트에 복사하지 않고, 별도의 승인된 평가 환경에서 동일 3건을 실행해야 한다.

## 현재 외부 AI 의존성

| 기능 | 현재 방식 | 로컬 대체 후보 |
|---|---|---|
| 답변 초안 | OpenAI Responses API, 구조화 JSON | Qwen/Llama/Gemma 계열 지시 모델 |
| 임베딩 | OpenAI `text-embedding-3-small` 기본 | BGE-M3, multilingual-e5 계열 |
| 안내서 Q&A 추출 | OpenAI 모델 | 로컬 지시 모델 + 규칙 기반 후보 추출 |
| 브라우저 요약 보조 | WebLLM Qwen2.5 0.5B + 규칙 대체 | 유지 또는 더 큰 로컬 모델 비교 |

## 실험 원칙

- 별도 `experiment/local-ai` 브랜치에서만 수행한다.
- AI 추론과 임베딩에 외부 AI API를 사용하지 않는다.
- 공식 법령 수집, Supabase 통신과 같은 일반 인프라 통신은 별도로 구분한다.
- 동일 평가 질문과 고정 근거 묶음을 OpenAI 기준 버전과 로컬 버전에 제공한다.
- 법령명·조문 환각은 일반 문체 품질보다 더 높은 실패 가중치를 둔다.

## 우선 비교 후보

- 경량 CPU/일반 PC: Ollama 또는 llama.cpp + 4bit Qwen 계열
- GPU 서버: vLLM + 중형 Qwen/Llama/Gemma 계열
- 임베딩: 한국어와 장문 검색을 함께 평가할 수 있는 다국어 모델
- 리랭커: 1차 키워드/벡터 후보에만 적용하여 지연시간을 제한

정확한 모델 버전·라이선스·하드웨어 요구량은 실험 착수 시 최신 공식 모델 카드로 다시 검증한다.
