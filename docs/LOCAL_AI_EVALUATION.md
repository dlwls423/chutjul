# 개인정보 우선 AI 대체 실험

상태: 브라우저 WebLLM 답변 생성 1차 구현·테스트 배포 완료. 운영 사이트에는 적용하지 않는다.

## 현재 외부 AI 의존성

| 기능 | 현재 방식 | 로컬 대체 후보 |
|---|---|---|
| 답변 초안 | 안정 버전은 OpenAI Responses API | 테스트 실험은 브라우저 Qwen2.5 0.5B/1.5B WebLLM |
| 임베딩 | OpenAI `text-embedding-3-small` 기본 | BGE-M3, multilingual-e5 계열 |
| 안내서 Q&A 추출 | OpenAI 모델 | 로컬 지시 모델 + 규칙 기반 후보 추출 |
| 브라우저 요약 보조 | WebLLM Qwen2.5 0.5B + 규칙 대체 | 유지 또는 더 큰 로컬 모델 비교 |

## 현재 구현

- 브라우저 메모리와 모바일 여부에 따라 Qwen2.5 1.5B 또는 0.5B를 선택한다.
- 동일 모델 엔진을 비식별 요약과 근거 선별·초안 생성에 재사용한다.
- 서버는 승인된 비식별 요약과 부서 범위 근거 최대 4개만 브라우저에 제공한다.
- 브라우저 결과는 서버에서 JSON 구조, 허용 근거, 법령 조문, 개인정보를 재검사한다.
- WebGPU 실패 시 OpenAI로 자동 우회하지 않는다.
- 테스트 사이트에서 실제 모델 다운로드와 초안 생성을 확인했다.

## 실험 원칙

- 서버 로컬 모델은 `experiment/local-ai`, 브라우저 모델은 `experiment/browser-ai`에서 분리한다.
- AI 추론과 임베딩에 외부 AI API를 사용하지 않는다.
- 공식 법령 수집, Supabase 통신과 같은 일반 인프라 통신은 별도로 구분한다.
- 동일 평가 질문과 고정 근거 묶음을 OpenAI 기준 버전과 로컬 버전에 제공한다.
- 법령명·조문 환각은 일반 문체 품질보다 더 높은 실패 가중치를 둔다.

## 우선 비교 후보

- 경량 CPU/일반 PC: Ollama 또는 llama.cpp + 4bit Qwen 계열
- GPU 서버: vLLM + 중형 Qwen/Llama/Gemma 계열
- 임베딩: 한국어와 장문 검색을 함께 평가할 수 있는 다국어 모델
- 리랭커: 1차 키워드/벡터 후보에만 적용하여 지연시간을 제한

정확한 모델 라이선스·브라우저별 WebGPU 지원·모델 배포 캐시는 운영 검토 시 최신 공식 자료로 다시 확인한다.

## 평가 산출물

- 고정 테스트셋과 실행 스크립트
- 정확성, 법령 검색, 환각, 한국어 품질, 평균/P95 지연, 오류율, CPU/RAM/GPU/디스크
- 동일 질문의 답변·근거 비교표
- 예상 월 운영비와 장애·업데이트 절차
- 운영 반영 권고 또는 보류 결론

## 아직 측정하지 않은 항목

- 고정 평가 질문의 OpenAI/Qwen 0.5B/Qwen 1.5B 정답·근거 일치율
- 존재하지 않는 법령·조문 생성률
- 최초 모델 다운로드 시간, 재방문 준비 시간, 평균/P95 생성 시간
- 모바일·내장 GPU·저메모리 PC의 실패율과 메모리 사용량
- 임베딩과 안내서 Q&A 추출의 외부 AI 제거 시 검색·추출 품질
