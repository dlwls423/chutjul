## 2026-10-18 — 신용정보법 동기화 및 양 사이트 배포

### 적용

- 필수 신용정보법 계열 4종을 동기화 시작 전에 자동 등록하도록 보강했다.
- 운영 사이트에서 법령 동기화를 실행해 26개 대상을 확인하고 신규 2개 버전을 저장했다.
- 신용정보법·시행령의 조문 본문, 시행일, 공식 출처가 검색 결과에 표시되는 것을 확인했다.
- 국가법령정보센터 응답의 항·호·목 값이 조문번호로 오인되던 경로를 차단했다.
- 이미 저장된 `제①조`, `제1.조` 형태의 잘못된 항목은 검색 결과에서 제외하고, 다음 동기화부터 정상 조문번호만 저장한다.

### 검증 및 배포

- 법령 질의 회귀 검사, TypeScript 검사, 프로덕션 빌드 통과
- 운영 동기화 결과: `partial`, 확인 26건, 변경 2건, 실패 1건
- 실패 대상은 기존 행정규칙 `개인정보 보호책임자 경력 인정에 관한 고시`이며 신용정보법 검색 기능과는 무관하다.
- 기본 사이트와 테스트 사이트에 동일한 검색 개선을 배포했다.
