## TASK 1 세부 백로그

- 답변 초안 생성 후에도 답변 방향성을 편집하고 선택 근거로 재작성 가능하게 한다.
- 관련도 옆에 산정 기준 안내를 제공한다. 현재 값은 통계적 확률이 아니라 제목·본문·질의·조문 등의 키워드 일치 가중치다.
- 단일 저정보 단어만 맞는 검색 결과를 억제하고 검색 품질 평가셋을 만든다.
- 법령 결과 카드와 상세 화면에 조문 본문, 시행일, 공식 출처를 일관되게 표시한다.
- 검색 AI 모델 안내: 현재 통합 검색의 핵심 랭킹은 AI 모델이 아니라 규칙 기반 키워드 점수이며, 임베딩은 업로드 시 생성되지만 운영 검색 결합은 제한적이다.
- 차별점 설명: 부서 범위, 민원 2트랙, 담당자 전송 승인, 법령 현행화, 근거별 재작성과 출처 고정을 중심으로 정리한다.
