# 첫줄

## 프로젝트 정보

- 만든이: 이예진
- 분야: 공공 민원 업무 지원 · 개인정보 보호형 문서 검색
- 한줄 요약: 개인정보를 보호하며 과거 민원과 법령을 찾아 민원 답변 준비를 돕는 웹 서비스입니다.

## 프로젝트 소개

민원 담당자가 유사 민원, 안내서, 관련 법령을 한 화면에서 검색하고 근거를 확인할 수 있도록 돕습니다. 민원 자료는 등록 전 브라우저에서 개인정보 보호 처리를 거쳐 검색용 자료로 활용합니다.

## 해결하려는 문제

민원 답변을 준비할 때 과거 사례와 최신 법령을 각각 찾아 확인하는 과정에 시간이 많이 듭니다. 민원 원문을 AI나 외부 서비스에 다루는 과정에서 개인정보가 노출될 수 있는 문제도 줄이고자 합니다.

## 현재 구현한 주요 기능

- 민원 PDF와 안내서 PDF를 등록하고 처리 현황을 확인합니다.
- 브라우저에서 개인정보를 탐지·마스킹하고, WebGPU 환경에서는 로컬 AI로 핵심 내용을 구조화합니다.
- 유사 민원, 안내서, 현행 법령을 통합 검색하고 유형·업무 분류·관련 법령으로 결과를 좁힙니다.
- 민원 질의·답변, 안내서의 일치 문장과 PDF 페이지, 처리 메타데이터를 상세 화면에서 확인합니다.
- 국가법령정보센터 API 기반 법령 수집·버전 관리·정기 동기화 코드를 구성했습니다.

## 앞으로 만들거나 개선할 내용

- 작성하거나 완료한 민원을 관리하는 기능을 구현합니다.
- 답변 자동화 작성 시 프롬프트를 추가해 답변의 방향성을 지시하는 기능을 구현합니다.
- 새 민원 분석, 근거 선택, 답변 초안 생성·저장과 검토 이력을 실제 업무 흐름으로 연결합니다.

## 활용할 수 있는 업무·상황

- 개인정보보호 관련 민원 답변을 준비할 때 유사 사례와 근거 법령을 찾는 업무
- 부서별로 축적된 민원·안내서 자료를 안전하게 검색하고 확인하는 업무
- 법령 개정 여부를 반영해 답변 근거를 점검하는 상황

- 개인정보 보호 처리 단계와 한계가 화면에서 충분히 명확하게 보이나요?
- 답변 자동화에서 사용자가 원하는 답변 방향을 자연스럽게 지시할 수 있을까요?

## 사용한 AI·개발 도구

- Next.js · React · TypeScript: 웹 서비스 화면과 API 구현
- Supabase: 인증, 데이터베이스, 파일 저장소 연동
- WebGPU · Qwen 로컬 모델: 브라우저 내 민원 핵심 내용 구조화 보조
- OpenAI 임베딩 API: 보호 처리된 검색 자료의 임베딩 생성
- 국가법령정보센터 API · GitHub Actions: 법령 수집과 정기 동기화 구성

## 다른 참가자가 참고할 만한 구현 방식

- 민원 원문을 외부로 보내기 전, 브라우저에서 개인정보를 마스킹하고 이미지형 PDF 사본을 만드는 흐름
- WebGPU 로컬 AI를 우선 사용하고, 사용할 수 없는 환경에서는 규칙 기반 처리로 대체하는 방식
- 부서별 자료 접근 범위와 공통 법령 자료를 구분해 검색하는 구조
